# macOS 风格界面改版说明

这次按「桌面参数检查器 + 绘图区」组织界面。参考了 Apple macOS 设计指南的桌面布局和操作密度，以及 Puppertino 的 Mac 分段控件、输入框和工具栏示例。具体样式用原生 CSS 实现，沿用系统字体和现有 HTML 打包方式。

## 可以复用的规则

| 部位 | V10 的做法 |
| --- | --- |
| 顶栏 | 宽窗口用 60 px 高的一行工具栏。左边放标题和两段式模式切换，右边放撤销、重做、载入、保存和图片导出。低频命令放进「更多操作」。保存方案使用实色蓝，其余按钮用浅底。 |
| 参数栏 | 用一整块浅灰底承载各组参数，组间用 1 px 细线分隔。数值输入成对排布，下拉按需占整行，标签和单位放在输入框上方。输入框高度 30 px，圆角 7 px，只读项用不同底色区分。 |
| 图表区 | 使用实白画布、12 px 卡片圆角和细边框。两张主图共用高度，尺寸和余量放在下面。保留原有光路颜色、线宽、标注字号与图例语义。 |
| 窗口尺寸 | 桌面参数栏与结果区独立滚动。940 px 及以下让操作按钮换到第二行，760 px 及以下改为单列且图表优先，500 px 及以下允许标题、模式和操作分别占行。 |

## 在其他工具里怎么套用

1. 先用现有页面截一张基准图，记录常用操作、首屏内容和必须保持的图表细节。
2. 建一份仅针对外壳和控件的样式表，把颜色、圆角、高度和间距写成 CSS 变量。重排时移动原有控件，保留事件和字段绑定。
3. 给图表留出稳定的区域，避免菜单开合、切换模式和短提示改变图框尺寸。数据配色留给设备、结果和警告。
4. 用同一组数据比较旧版和新版，覆盖宽屏、窄窗、键盘操作及导出。离线 EXE 要用实际内嵌页面再验一次。

在本项目里，样式集中于 `网页源码/workbench-theme.css`，顶部控件组织在 `网页源码/ui-layout.js`，构建时将样式内嵌到单页 HTML。后续工具可以先复用 CSS 变量，再按自己的操作流程排列控件。
