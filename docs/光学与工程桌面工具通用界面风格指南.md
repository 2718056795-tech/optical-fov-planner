# 光学与工程桌面工具通用界面风格指南

适用于光学选型、计算器、数据分析和图表查看等以键盘、鼠标为主的桌面工具。统一以 **macOS 桌面应用**为视觉和交互基准，优先参考 Apple 官方 Mac UI Kit、AppKit 界面示例与 Puppertino 的 Mac 控件。V10 是已有的桌面实现，后续改版可用它作前后对照。 [Apple Design Resources](https://developer.apple.com/design/resources/) · [Apple macOS 设计指南](https://developer.apple.com/design/human-interface-guidelines/designing-for-macos) · [Puppertino 桌面组件](https://puppertino.com/docs/desktop/)

## 1. macOS 窗口与布局

| 区域 | 通用做法 | 按项目调整 |
| --- | --- | --- |
| 顶部工具栏 | 标题靠左，模式切换紧跟标题，常用动作成组放在右侧。有明确下一步时突出一个主操作。低频命令放进有明确标签的「更多操作」。 | 需要手动运行时可突出「计算」。参数一改就出图的工作区可使用中性工具栏，让图和关键读数成为视觉重点。 |
| 左侧参数栏 | 参数较多时用连续浅灰底和 1 px 分隔线。依业务顺序分组，例如安装、相机、光机。成对的数值字段并排，长名称或下拉选择按需占整行。 | 参数少的工具可用顶部一行或一组内联控件。流程型工具按步骤排列。 |
| 主工作区 | 首屏展示主要结果。并排图框共用顶线和高度，图表用实底。详细数值、备注和次要结果放在主图下方。 | 图表型工具优先展示主图。表格型工具优先展示核心表格，辅助图放在第二层。 |
| 窗口收窄 | 先让工具栏换行，再把并排图改成单列。桌面双栏时，参数和结果可以独立滚动。 | 用标签是否截断、图表最小可读宽度和按钮是否可达来定断点。V10 的 940、760、500 CSS px 可作测试起点。 |

### Mac 风格的三个窗口层次

#### 统一工具栏与图标

标题和常用命令共用一条紧凑顶栏。标题、当前方案名和只读状态用普通文字。有明确主操作时用强调色，同级命令用中性样式。沿用 Windows 原有的窗口控制。 [Apple 工具栏规范](https://developer.apple.com/design/human-interface-guidelines/toolbars) · [Apple 按钮层级](https://developer.apple.com/design/human-interface-guidelines/buttons)

- **相关命令共用底面。** 「撤销／重做」放在一块浅底里，组内按钮用各自的悬停、按下和焦点状态。分段切换、下拉和独立主按钮各自成组，组间留出间距。格式选择可以紧邻「导出」，让用户在执行前看到当前格式。 [Apple AppKit 工具栏示例](https://developer.apple.com/videos/play/wwdc2025/310/) · [Puppertino 工具栏](https://puppertino.com/docs/desktop/toolbars/)
- **整条工具栏使用同一套图标。** 对齐图标与文字的视觉基线，统一线宽和视觉重量。辅助图标跟随中性文字色，强调色用于主操作或选中状态。只用图标时提供可访问名称和简短提示。像「恢复默认参数」这类容易误读的命令保留文字。 [naplesblue 图标规则](https://github.com/naplesblue/apple-design-skill/blob/main/icons.md) · [Puppertino 提示](https://puppertino.com/docs/desktop/tooltips/)
- **嵌套圆角彼此对齐。** 分段轨道和选中面四周留等距时，内层圆角按外层圆角减去内边距来定，让两条弧线保持同心。分段控件用于同一处的相关选项，例如「空间示意／侧视」。多个独立工作区采用页签或侧栏。 [Apple 控件形状](https://developer.apple.com/videos/play/wwdc2025/356/) · [Apple 分段控件规范](https://developer.apple.com/design/human-interface-guidelines/segmented-controls?changes=_4)

#### 可调宽、可收起的参数栏

参数栏用连续浅灰面板贴邻工作区。组标题和短细分隔线区分「安装」「相机」「光机」，输入框和标签按列对齐，相关数值可同排。设备身份用标题或图例表达，详细说明按需展开。 [Apple AppKit 分栏、侧栏与检查器示例](https://developer.apple.com/videos/play/wwdc2025/310/)

- **拖动分隔线调整宽度。** 桌面双栏可以拖宽参数栏来显示完整的字段名、单位和下拉选项。按两侧的内容设置最小宽度，给图表留出轴标签和读数所需的空间。窄窗沿用前面的换行和单列规则。 [Apple AppKit 分栏交互](https://developer.apple.com/documentation/appkit/nssplitviewcontroller-protocol-implementations?changes=la)
- **用固定入口收起和恢复参数栏。** 例如在视野工具顶栏放「隐藏参数／显示参数」，收起后给主图腾出宽度，恢复时回到上次可用的栏宽。调整过程中保留当前输入和图表的缩放、平移位置。重新展开时按当前窗口宽度限制栏宽。
- **收起后仍能看见影响结果的设置。** 常用参数直接显示，次要参数可点组标题展开。收起时，标题旁只列出当前模型中生效且影响读数的非默认设置，例如「光心后移 +8 mm」。切到忽略后移量的倍率模型时，摘要随之清除。 [Puppertino 展开控件](https://puppertino.com/docs/desktop/disclosure-controls/)

#### 内容与浮层

图表、表格和密集读数使用稳定的实底。顶部工具组、菜单等浮层可以按需借鉴浅半透明材质，并保留实底回退。系统启用「减少透明度」时，浮层使用不透明底。高对比度下用清晰的轮廓区分浮层和内容，两项可分别验证。 [Emil 的辅助显示规则](https://github.com/emilkowalski/skills/blob/main/skills/apple-design/SKILL.md#14-reduced-motion--accessibility) · [applecn 的材质与对比度](https://github.com/STiXzoOR/applecn/blob/main/.agents/skills/applecn/SKILL.md#using-it)

控件的形状随用途和尺寸变化。紧凑检查器用小圆角矩形，较大的突出控件可用胶囊。 [Apple 的桌面控件尺寸与材质](https://developer.apple.com/videos/play/wwdc2025/356/) · [Apple 材质规范](https://developer.apple.com/design/human-interface-guidelines/materials)

## 2. 共用主题值

以下值是工程桌面的起步配置。控件高度要随文字缩放和内容密度调整，页面内同类控件保持一致。建议由一份样式表、主题资源或常量模块集中管理。

| 用途 | 默认值或规则 |
| --- | --- |
| 窗口底 / 参数栏 / 内容面 | `#F4F5F8` / `#EEEFF3` / `#FFFFFF` |
| 分隔线 / 内容区细分隔线 | `#DCDFE6` / `#E7E9EE` |
| 主文字 / 次文字 | `#202127` / `#5C606B` |
| 主按钮底色 / 键盘焦点 | `#0064D6` / `#007AFF` |
| 控件高度 / 控件圆角 / 内容卡片圆角 | 30 px / 7 px / 12 px |
| 区块间距 / 窄间距 | 12 px / 6 px |
| 字体与字重 | 系统无衬线字体。紧凑桌面界面可从标题 20 px、组标题 14 px、控件与标签 12–13 px 起步。需要逐行比较的数值可使用等宽数字。 |
| 视觉层级 | 大面积用浅灰与白。分组靠间距和细线。浮层可用轻阴影。数据色用于区分设备、系列、选中项和状态，并配文字、线型或图例。 |

新项目的主按钮蓝比 V10 的 `#007AFF` 深一级。`#0064D6` 配纯白字的对比度约为 5.54∶1，可作为小字号主按钮的默认组合。常规文字可以 4.5∶1 为对比度参考，按实际背景复核。 [W3C 文字对比度指南](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

## 3. 控件与交互

### 三类优先统一的控件

| 控件 | Mac 风格外观 | 交互要核对 |
| --- | --- | --- |
| **分段切换** | 用紧凑的圆角轨道包住等高的分段，同组文字或图标在同一基线上。活动段用清楚的填充或选中面表达。 | 选中、悬停和键盘焦点能分别辨认。切换时整组尺寸稳定，沿用项目现有的导航与快捷键。 |
| **工具栏按钮** | 相关操作在同一组，组内同高、同基线。常见操作可以使用简洁图标，含义容易混淆时保留文字。有明确主操作时单独突出。 | 检查默认、悬停、按下、焦点、禁用。图标按钮提供可访问名称。禁用按钮保留位置，菜单关闭后焦点回到入口。 |
| **数值输入** | 小圆角矩形和清楚的输入边界。字段与单位用稳定标签表达，同列数值和单位按用途对齐。步进器用于有实际步长的字段。密集参数栏可在鼠标悬停或键盘聚焦时显示步进箭头，触摸和高对比度模式下保留清楚的步进入口。 | 区分可编辑、只读、禁用和错误。键盘可输入负号和小数，也能粘贴。遵守原有精度、单位、范围和 Tab 顺序。 |

控件细节先与 Mac 示例逐项比较，再根据工程字段长度微调。为 30 px 的桌面控件预留放大后的布局空间。按项目支持的窗口与 Windows 缩放设置检查文字、按钮和焦点。 [Apple 文本输入规范](https://developer.apple.com/design/human-interface-guidelines/text-fields) · [Apple 无障碍指南](https://developer.apple.com/design/human-interface-guidelines/accessibility?changes=l__3&language=objc) · [Puppertino 桌面表单](https://puppertino.com/docs/desktop/forms/)

- **参数输入。** 字段名和单位放在输入上方。给只读、禁用、无效和正在编辑的字段各自清楚的状态。错误就近显示，并指出可修改的字段。显示位数可以少于计算精度，输入失焦或切换模式时保留底层数值。
- **菜单与快捷键。** 「更多操作」可用键盘打开，支持 Esc 或点击外部关闭，关闭后焦点回到触发位置。保留已有快捷键、导入导出入口和文件格式。同组图的「导出」「放大」等命令在各图标题栏按相同顺序靠右排列，与视角分段之间留出组距。
- **反馈与动效。** 按钮按下及时响应。切换状态、显示提示或开合菜单时，主图和数据列保持原位。短动效适合交代状态变化，连续拖动或缩放应及时跟手，并尊重减少动态效果的设置。 [Emil Kowalski 的 Apple Design 指南](https://github.com/emilkowalski/skills/blob/main/skills/apple-design/SKILL.md)
- **图表与读数。** 绘图样式独立于界面主题。复用主题时沿用已有的线宽、字号、比例、坐标和颜色语义。状态信息同时给文字或符号，方便区分「余量」「贴边」「超出」等情况。关联图可分别放大或滚动查看时，在各自图题下同步标出所绘工况，例如「远端 · WD 150 mm」。工况文字按读数的字号呈现。

### 贴着控件展开的浮层

- **把短设置放在操作发生的位置。** 例如从图框右上角的「显示设置」打开图例、网格和标注选项。浮层贴着触发按钮展开，靠近窗边时换到空间足够的一侧，主图和数据列留在原位。「更多操作」里的命令仍用菜单。 [Puppertino 桌面浮层](https://puppertino.com/docs/desktop/popovers/)
- **开合沿同一路径。** 关闭时沿原路径收回，连续点击可以从当前过渡位置反向。键盘可打开，按 Esc 或点击外部可关闭。键盘关闭后焦点回到触发按钮，开启减少动态效果时使用简单淡入淡出或直接切换。 [Emil 的空间一致性规则](https://github.com/emilkowalski/skills/blob/main/skills/apple-design/SKILL.md#7-spatial-consistency--symmetric-paths-anchored-origins)

### 按场景采用的规则

- **并列读数。** 需要横向比较的同类结果共用一个标题和单位，按相同的指标顺序对齐。例如三种景深公式各占一列，近界、远界、总景深各占一行。可单独放大或导出的图保留各自图框。 [naplesblue 的结果分组思路](https://github.com/naplesblue/apple-design-skill/blob/main/patterns.md#decision-trees)
- **结果表格。** 适用于需要跨列比较或选行查看的结果表，例如变焦运动表、镜头方案对比和优化历史。宽表可用浅色交替行底，数值列右对齐，同列单位一致时写在表头。对有比较价值的列提供排序和方向提示，并允许拖动列宽。表格有焦点时强调选中行，焦点移开后用低调底色保留选择。 [Puppertino 桌面表格](https://puppertino.com/docs/desktop/lists-tables/) · [Apple 列表与表格指南](https://developer.apple.com/design/human-interface-guidelines/lists-and-tables?changes=_5)
- **图表精细操作。** 适用于支持拖动标记或滚轮缩放的交互图，例如定位光路交点、查看畸变曲线局部。拖动标记时保留鼠标按下时的抓取偏移。滚轮缩放以鼠标下的数据位置为锚点，在轴范围允许时让该位置停在原来的屏幕位置。 [Emil 的直接操控规则](https://github.com/emilkowalski/skills/blob/main/skills/apple-design/SKILL.md#2-direct-manipulation--11-tracking)
- **跨工况对比。** 同一物理坐标中的视图采用一致的坐标原点、单位和比例，方便辨认真实位移和尺寸变化。单个可选图层可用带文字的复选框放在图框标题旁，图例沿用图层的线型或符号。切换图层时固定绘图区及其坐标范围。图下读数和图例复用现有位置。
- **尺寸与结果状态。** 按物理含义标注尺寸，例如「边长」「X/Y 外包络」「面积」，并注明单位和适用工况。输入缺失或无效时就近提示需修正的字段。有效计算得到空区域时显示「无重合」等明确状态，并清除旧轮廓。数据导出中缺失值留空，并用状态列说明原因。真实零值填写 0。
- **图表与数据导出。** 单图导出沿用当前工况、可见图层和标注，并在图片内保留理解读数所需的图例、单位和工况。CSV 等数据导出保留计算精度和必要的状态字段，供后续复核。
- **长计算反馈。** 适用于工况扫描、批量分析和镜头优化等需要等待的任务。在结果区固定位置显示任务状态。能统计总量时显示真实完成数，例如「已完成 32 / 100 个工况」。进度无法量化时显示当前阶段和活动指示。输入已变更且仍显示旧结果时，在旧图或表旁标注「上次结果 · 待更新」，等对应当前输入的结果发布后清除标注。 [applecn 进度组件](https://github.com/STiXzoOR/applecn/blob/main/.agents/skills/applecn/SKILL.md#controls) · [Apple 进度指南](https://developer.apple.com/design/human-interface-guidelines/progress-indicators?changes=_4_6)

## 5. 改版交付前检查

- [ ] 用 Mac UI Kit 或 AppKit 示例核对工具栏、检查器和控件状态，再用同一组数据的改版前后截图确认关键结果在首屏可见。
- [ ] 在宽窗、最窄支持窗口和常用 Windows 缩放下检查文字、按钮和图表。用到半透明浮层时，分别开启减少透明度和高对比度，核对文字、边界和选中状态。
- [ ] 核对工具栏同组底面、图标和选中状态。拖动、收起和恢复参数栏后，参数和当前图表视角仍可接续。收起高级参数和切换计算模型时，核对标题摘要与实际参与计算的值是否一致。
- [ ] 检查窄窗下的浮层位置和开合方向。用键盘打开浮层并按 Esc 关闭，焦点回到触发按钮。打开菜单、切换模式、滚动参数栏和关闭放大视图后，主图位置及参数状态符合原来的操作预期。
- [ ] 验证 Tab、Enter、Esc 和原有快捷键。输入焦点可见，弹层关闭后可以继续操作。
- [ ] 按适用场景验证表格排序、列宽和失焦后的选中状态，图表标记抓取与缩放锚点，以及长计算进度和待更新标记。
- [ ] 在同一窗口和同一组参数下切换比较工况或图层，核对绘图区边界、坐标比例及图例。用缺失输入、空结果和有效结果各复核一次界面与导出的数值、单位及状态。提供 EXE 时，在实际打包后的程序中复验一次。
